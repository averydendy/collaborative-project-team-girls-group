# Collaborative

This repository is a group project for practicing with Git and Github as a team. Each member has their own branch that they work on before it is committed and pulled. We were tasked with fixing merge conflicts.

## Files

- `.gitignore`: list of files and folders that Git should not track
- `collaborative-project-team-girls-group.Rproj`: RStudio project file
- `plots_un.R`: R script for fix merging conflict
- `TEAMWORK.md`: describes each team members' task and timeline for completion 
- `README.md`: this file, overview of the project
